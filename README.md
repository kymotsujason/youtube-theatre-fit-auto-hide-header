# YouTube Threatre Fit + Auto-hide Headers

[![Install](https://img.shields.io/badge/Install-Tampermonkey-00485B?style=for-the-badge&logo=tampermonkey)](https://github.com/kymotsujason/youtube-theatre-fit-auto-hide-header/raw/refs/heads/master/youtube-theatre-fit-auto-hide-header.user.js)

To use, either click the install button above or create a new script in TamperMonkey and copy in the contents of the script in this repo. This will ensure the YouTube video player takes up the entire viewport while moving the title to the in-player controls. There's also a rotate button and the subtitle, autoplay, default view, and fullscreen buttons are hidden.
